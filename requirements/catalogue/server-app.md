# server-app — desktop wrapper around the API

Runs the API on one Mac: tray, supervision, backup, worker enrolment. Rows tagged `W` in the server inventory, plus
the `W` half of `W+A` rows. There is no separate front: the API serves the browser client and binds the app's port itself (ADR-0006).
Front rows are retired or moved to the API. Columns are explained in
[../README.md](../README.md).
