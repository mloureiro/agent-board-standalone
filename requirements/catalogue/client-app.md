# client-app — desktop wrapper around the browser client

Bundles the browser client of the same release and adds the native surface: windows, tabs, keychain, native
notifications, links, menus, zoom, release. It loads no page from a server, so the old shell's page patching is
gone by design (client inventory §5). Each server opens in its own window with its own tab strip, plus one "All servers" window; isolation is a namespace per server id inside the bundled client (ADR-0005), and every server request goes through the native bridge (ADR-0004). Columns are
explained in [../README.md](../README.md).
