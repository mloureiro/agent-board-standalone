# cli — the engine on each host running `claude`

Replaces `board` with every command and flag it has (R2.2), merged from both of today's lines (`main` and
`local-server-v2`), plus the gaps in [../cli-review.md](../cli-review.md). Columns are explained in
[../README.md](../README.md).
