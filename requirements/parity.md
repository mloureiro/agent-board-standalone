# Parity problems P-01…P-20

The twenty recorded client/server parity failures ([client inventory §2](inventories/client-inventory.md)), each
linked to the catalogue rows that prevent it and the kind of test that would have caught it (R2.3). "Gone by design"
means the cause cannot exist once the client app bundles the browser client (no page patching).

Test kinds: **contract** = the contract package's own suite (schemas, feature constants, compatibility function);
**e2e** = the suite connecting API, CLI and browser client (Chromium and WebKit, phone and desktop);
**part** = the owning part's own suite; **wrapper** = the client app's or server app's own suite.
