# Changelog

## 1.0.0

The tray-only macOS app that runs the API on one Mac: supervised API and worker, backup and restore with a pre-upgrade
backup, enrolment of the worker through the Keychain, a login item, rotating redacted logs and a headless runner. The
bundle carries the API single executable, the CLI binary and the browser client, all signed with one ad-hoc identity,
which `sign:check` verifies.
