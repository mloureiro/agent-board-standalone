5. Keys that can wait

      

        Android release keystore: only while finalising step 13 of the install, run from a clone of
        the repository
      

      
sh scripts/keys/android-keystore.sh

      
Until then the Android app is built with a throwaway key.

      
CLI update signing key: from a clone of the repository, run

      
sh scripts/keys/minisign-init.sh

      

        Commit and merge apps/cli/update-key.pub before the CLI release build you
          keep.
        A CLI built earlier trusts no key and checks checksums only.
